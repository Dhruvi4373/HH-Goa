# HH-Goa

This is a React application built with [Vite](https://vitejs.dev/), [TypeScript](https://www.typescriptlang.org/), and [Tailwind CSS](https://tailwindcss.com/).

## Prerequisites

- [Node.js](https://nodejs.org/) (version 16 or higher recommended)
- npm (comes with Node.js)

## Getting Started

1. **Install dependencies:**

   Run the following command to install the required packages:

   ```bash
   npm install
   ```

2. **Run the development server:**

   Start the application locally by running:

   ```bash
   npm run dev
   ```

   This will start the Vite development server. Open your browser and navigate to the URL provided in the terminal (usually `http://localhost:5173/`) to view the application.

## Available Scripts

In the project directory, you can run the following commands:

### `npm run dev`

Starts the development server with hot module replacement (HMR).

### `npm run build`

Compiles the TypeScript code and builds the application for production into the `dist` folder. It optimizes the build for the best performance.

### `npm run preview`

Boots up a local static web server that serves the files from the `dist` folder. It's useful for previewing the production build locally before deploying.

### `npm run lint`

Runs the TypeScript compiler to check for type errors.

## Tech Stack

- **React:** UI library
- **Vite:** Build tool and development server
- **TypeScript:** Typed superset of JavaScript
- **Tailwind CSS:** Utility-first CSS framework
- **Lucide React:** Icon library
